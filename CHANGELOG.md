# Changelog

## 1.2.0 — Primera versión pública

- Widget Windows con interfaz web local, vistas compacta/ampliada, pin y bandeja.
- CPU, RAM, actividad/transferencia de discos, GPU y batería.
- Salud de batería, desgaste, capacidades y ciclos cuando se informan.
- Historial SQLite de 30 días, registro diario de salud de un año y CSV.
- Diagnósticos HTML/JSON y reportes nativos de batería de Windows.
- Temperaturas medidas separadas de límites de advertencia/críticos y distancia a TjMax.
- Modelo de equipo y conteo de núcleos/hilos detectados en tiempo de ejecución.
- PawnIO opcional desde su origen oficial, con descarga verificada por SHA-256.
- Scripts de build/pruebas/empaquetado, lock NuGet, plantilla CI Windows y documentación.

La versión pública parte de un prototipo local. Sus métricas, reportes y datos personales no se distribuyen.
